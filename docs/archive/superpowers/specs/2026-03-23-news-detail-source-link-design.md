# News Detail Source Link Promotion Design

## Context

当前 `News Feed` 点击新闻卡片后会进入站内 `News Detail` 页面，详情页顶部也已经有一个文字型“打开原文”链接。

但这个入口的可见性偏弱：

- 用户进入详情页后，注意力容易先被标题、情绪标签和分析区吸走
- “打开原文”只是普通文本链接，不像一个明确动作
- 对于“先看详情，再决定是否跳原文”的使用路径来说，当前入口不够直接

这导致用户虽然理论上能去原文，但在实际浏览中仍然像“只能看站内页”。

## Options

### Approach A: 仅增强详情页原文入口

保留 `News Feed -> News Detail` 现有路径，只把详情页顶部的原文入口升级成更明显的按钮。

优点：

- 改动最小，风险低
- 不改变用户现有“进详情做分析”的路径
- 与当前页面结构完全兼容

缺点：

- 列表页不能直接外跳

### Approach B: Feed 卡片增加双入口

列表卡片继续进入详情页，同时在卡片上额外提供“原文”按钮。

优点：

- 列表页和详情页都能打开原文

缺点：

- `NewsCard` 交互更复杂，移动端点击区更容易冲突
- 会把本次需求扩展成列表级交互改造

### Approach C: 整张卡片外跳，详情页改成次级入口

优点：

- 去原文最快

缺点：

- 与当前“先分析再决定”的核心诉求相反
- 会破坏现有详情分析流

## Recommended Design

采用 Approach A。

### Interaction

- `News Feed` 维持现状，点击卡片进入 `News Detail`
- `News Detail` 顶部信息区保留原文入口，但改成显式主动作按钮
- 按钮文案使用“打开原文”
- 点击后以新标签页打开 `canonical_url`
- 如果当前新闻没有 `canonical_url`，则不渲染该按钮

### Visual Treatment

- 入口放在标题下方的元信息区域，与来源、时间、情绪标签同一块显示
- 样式采用现有蓝色渐变按钮语言，和“分析标的”“查看主题”等动作保持一致
- 按钮不需要额外图标，重点是显著性和一致性

### Testing

前端测试覆盖：

- 有 `canonical_url` 时显示显式“打开原文”按钮，且链接属性正确
- 没有 `canonical_url` 时不显示该按钮
- 详情页仍然不回退到旧的正文展示区

## Expected Outcome

完成后，用户仍然会先进入带分析能力的详情页，但进入页面后能立即看到去原文的明确动作，不再需要在文本信息里找普通链接。
