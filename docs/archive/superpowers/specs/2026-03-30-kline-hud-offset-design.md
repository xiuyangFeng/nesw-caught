# K 线 HUD 浮层下移设计

**背景**

当前 `KlineChart.vue` 顶部的行情 HUD 浮层用于展示开高低收、涨跌和成交量，但它与图表顶部标签区和主图上沿距离偏近。在部分数据形态下，浮层会更明显地压住主图顶部区域，影响顶部 K 线与均线的观察。

**目标**

在不改变 HUD 内容、交互和信息密度的前提下，仅把该浮层向下调整少量距离，减少对主图顶部的视觉遮挡。

## 范围

- 调整 `KlineChart.vue` 中 `data-role="kline-hud"` 的垂直定位。
- 为该定位补充组件测试，避免后续样式回退。

## 不在范围

- 不改动 HUD 字段、颜色、文案和交互。
- 不调整 K 线数据、指标逻辑、右侧面板或副图。

## 方案对比

### 方案 A：仅下移 HUD 定位

- 优点：改动最小，风险最低，直接解决遮挡问题。
- 缺点：属于局部样式修正，不解决更大范围的图表密度问题。

### 方案 B：缩小 HUD 高度和字号

- 优点：也能减轻遮挡。
- 缺点：会影响现有可读性，且超出本次“只往下调一点”的诉求。

**推荐：方案 A。**

## 具体设计

- 将 `data-role="kline-hud"` 的 `top-14` 下调为更靠下的一档定位。
- 保持 `pt-24` 的主图区内边距不变，避免连带影响图表与副图布局。
- 在 `KlineChart.test.ts` 中补充 HUD 定位断言，锁定新的垂直偏移类名。

## 测试策略

- 先在 `KlineChart.test.ts` 增加 HUD 定位断言，并确认旧实现下测试失败。
- 修改样式后重新运行 `src/components/watchlist/KlineChart.test.ts`。
- 运行 `npm --prefix frontend run build`，确认前端构建不受影响。
