# 仪表盘市场情绪与动态行情设计

日期：2026-08-03

## 目标

将仪表盘底部低频使用的来源健康明细替换为面向投资决策的五市场情绪视图，并在突发新闻区域下方提供全球指数动态行情条。来源健康明细继续保留在运维页面，仪表盘复用既有 `/api/market/overview`，不新增后端接口。

## 方案

1. `DashboardView` 在挂载时加载 `marketOverviewStore` 并启用既有 60 秒轮询，卸载时停止。
2. `MarketTickerStrip` 展示五市场指数，过滤仅用于情绪计算的 `^VIX`，不可用报价降级为 `--`；列表双份渲染形成循环滚动，涨跌幅变化时短暂闪烁。
3. `FearGreedPanel` 将后端 `quant_sentiment.score [-1,1]` 映射为 0–100 半圆仪表，同时展示 VIX、涨跌比、平均涨跌、板块涨跌家数和新闻情绪。
4. 缺少量化情绪、板块或新闻样本时显示明确占位，不伪造数值。
5. 行情闪烁定时器必须在组件卸载时清理，避免路由切换后的残留回调。

## 风险与验收

- 日韩欧市场可能缺少部分输入，卡片允许显示数据不足。
- 来源健康从 Dashboard 移除，但 `/ops` 仍提供诊断入口。
- 组件测试覆盖渲染、降级、比例、闪烁和卸载清理；前端全量测试与构建必须通过。
