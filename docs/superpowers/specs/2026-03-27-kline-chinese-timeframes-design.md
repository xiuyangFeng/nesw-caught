# K 线指标页中文化与券商式周期设计

**背景**

当前自选股详情页的 K 线区域仍保留多处英文展示文案，例如 `Trading Desk`、`Settings`、`Session Range`、`Volume`、`Updated` 等；同时周期切换使用 `1D / 1W / 1M / 3M / 1Y` 这组混合语义，按钮名称与实际查询范围并不一致，不符合同花顺、东方财富一类用户对 `日K / 周K / 月K / 年K` 的直觉。

**目标**

在不改动指标缩写本身的前提下，将 K 线指标页所有面向用户的非缩写英文展示统一改成中文，并将周期入口调整为更贴近券商行情软件的 `日K / 周K / 月K / 年K` 语义，使按钮名称与实际图表行为一致。

## 范围

- 保留技术指标缩写：`MACD`、`KDJ`、`BOLL`、`MA5/10/20/60`、`DIF`、`DEA`、`K/D/J` 不翻译。
- 中文化范围包括：
  - 详情页顶部摘要区文案
  - 设置弹层文案
  - K 线图摘要区标签
  - 右侧仪表盘与技术读数中的非缩写英文标签
  - 副图 `VOL` 面板中的非缩写英文标签
  - 图表空态、加载态、更新时间等补充文案
- 周期入口改为 `日K / 周K / 月K / 年K`，并同步调整前端周期映射与显示标签。
- 前端内部允许继续使用既有 period key 作为状态值，但任何用户可见入口、激活态标签、摘要标签都必须显示为 `日K / 周K / 月K / 年K`，不能继续暴露 `1D / 1W / 1M / 1Y`。

## 不在范围

- 不修改后端返回的指标字段结构。
- 不将 `MACD / KDJ / BOLL / MA` 这类指标缩写替换成中文全称。
- 不新增真正按“年”为一根蜡烛的后端聚合逻辑。

## 周期语义设计

### 入口定义

- `日K`：日线粒度，查看近一年走势
- `周K`：周线粒度，查看近五年走势
- `月K`：月线粒度，查看近十年走势
- `年K`：第一版按长期年线视图处理，复用现有月线接口能力，使用月线粒度查看最大可用范围，并在界面上作为 `年K` 入口呈现

### 设计理由

- `日K / 周K / 月K` 直接对应用户最熟悉的 K 线粒度语义。
- 现有接口已支持 `1d / 1wk / 1mo` 粒度组合，前端可在不改 API 契约的前提下完成前三项。
- `年K` 若要求“每年一根蜡烛”，需要后端新增 yearly 聚合，超出本次优化范围；因此第一版采用“长期年线视图”策略，优先满足操作习惯和观察长期走势的需求。

## 页面文案策略

### 顶部摘要区

- `Trading Desk` 改为中文市场/K 线场景文案
- `Settings` 改为 `设置`
- `Updated` 改为 `更新时间`
- 状态提示改成中文，保留技术面含义但不出现英文夹杂

### 指标矩阵

- `Open / Prev Close / High / Low / Volume / Amplitude / Session Pos / Avg Vol 20 / 6M Pos`
  改为中文标签，如 `开盘 / 昨收 / 最高 / 最低 / 成交量 / 振幅 / 日内位置 / 20日均量 / 区间位置`

### 图表摘要和右栏

- `Interval / Range / Candles` 改为中文标签
- `Session Range / 6M Range / Bias vs MA20 / BOLL U/M/L / Avg Vol 20 / Volume / Close / Histogram`
  改为中文表达，但保留技术缩写，例如 `BOLL上轨`、`BOLL中轨`、`BOLL下轨`

## 数据流与组件边界

- `watchlistStore.ts` 负责维护新的周期枚举与请求参数映射。
- `StockDetailPanel.vue` 负责展示新的中文周期入口与顶部中文摘要。
- `KlineChart.vue` 负责图内摘要、仪表盘、技术读数、副图读数的中文化，以及对 `年K` 的摘要显示。
- 现有 `StockKlineResponse` 类型保持不变。

## 错误处理

- 周期切换继续沿用现有 `loadKline` 失败处理，不新增额外错误态。
- 若 `年K` 请求因数据源最大范围限制返回较少数据，前端仅按实际返回内容渲染，不额外报错。

## 测试策略

- 更新 `watchlistStore` 测试，验证新的 `日K / 周K / 月K / 年K` 到 `interval/range` 的映射。
- 更新 `KlineChart` 组件测试，验证中文摘要、中文右栏、副图区文案，以及 `年K` 对应的长期视图摘要显示。
- 更新 `StockDetailPanel` 测试，验证设置面板中新的中文周期按钮、`年K` 激活态，以及加载态/更新时间等中文文案。
