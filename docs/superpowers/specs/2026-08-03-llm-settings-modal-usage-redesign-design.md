# LLM 设置弹窗化与用量账本重设计

日期：2026-08-03

## 问题

LLM 设置页当前把完整新增/编辑表单常驻在页面右侧。服务预设、基础字段、价格、预算和密钥纵向堆叠，页面高度被低频操作长期占用。用量控制台则由四张等权指标卡、稀疏折线图和传统表格组成；数据只有一天时折线退化为孤立圆点，视觉重心空洞，难以快速读取 Token 构成和模型占比。

## 设计方向

采用“克制的量化控制台”方向：默认页面只展示模型连接状态、一个明确的配置入口和紧凑用量账本；复杂配置在用户主动点击后进入居中的专用窗口。

### 配置交互

1. 页面新增紧凑的“模型接入”提示卡，明确说明可填写服务地址、模型、API Key、价格和预算。
2. 点击“填写模型配置”后打开居中模态窗口；点击模型列表的“编辑”复用同一窗口并带入现有配置。
3. 模态窗口限制为 `max-height: 88vh`，表单内容内部滚动，页面背景保持稳定。
4. 支持右上角关闭、底部取消、点击遮罩和 Escape 关闭。
5. 保存成功后关闭窗口；失败时保留窗口和用户输入，由现有 toast/错误状态提示。

### 用量可视化

1. 四张大卡收敛为一条紧凑指标带：总 Token、成本、调用数、活跃模型。
2. 7 日趋势改为输入/输出 Token 堆叠柱状图；单日数据仍形成完整柱体，不再退化成孤立点。
3. 右侧展示模型用量排行、占比进度和成本，Top 模型按 Token 实际计算，不依赖后端数组顺序。
4. 预算状态使用一条明确的进度轨道；操作类型用紧凑标签补充，不再使用冗长表格。
5. 保留深色终端主题、等宽数字和现有颜色令牌，避免引入新的视觉体系。

## 验收

- 页面初始不渲染配置表单，只显示入口提示。
- 新增和编辑都在居中 dialog 中完成；保存成功自动关闭。
- 7 日图对单日和多日数据都可读，能区分输入/输出 Token。
- 模型排行、预算和空状态清晰；专项测试、前端全量测试与构建通过。
