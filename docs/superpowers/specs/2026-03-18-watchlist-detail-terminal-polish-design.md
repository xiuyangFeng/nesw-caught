# Watchlist Detail Terminal Polish Design

## 背景

在前几轮终端化改造后，自选股详情页整体已经进入深色体系，但 `指标详情` 区块的小指标卡和 `关联新闻` 区块的新闻卡仍然保留发灰的浅亮底板，和当前的冷蓝灰终端表面不一致，也削弱了可读性和科技感。

## 目标

- 把自选股详情页中的指标卡和关联新闻卡统一到深色终端表面。
- 提升卡片标题、正文和时间信息的对比度。
- 保持现有数据结构、布局和交互不变。

## 设计方案

- `metrics-grid article` 改成深色终端卡，使用更深的面板底色、清晰的标题和数值层级。
- `related-card` 改成与其他页面一致的深色新闻卡，保留 sentiment pill 和来源信息，但不再依赖浅灰底。
- 为这两类卡片补 `data-surface` 钩子，便于测试和后续维护。

## 测试与验证

- 新增 `WatchlistDetailView` 测试，验证指标卡和关联新闻卡具备新的终端表面钩子。
- 跑目标测试和前端构建。
