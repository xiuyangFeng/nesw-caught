# LLM Settings Terminal Input Design

## 背景

在上一轮高对比终端化修复后，大部分卡片和表格已经回到深色终端表面，但 `LLM Settings` 页的表单输入框仍然是大面积白底，和整体蓝黑终端风格冲突，也会在深色页面里形成刺眼的亮块。

## 目标

- 移除 `LLM Settings` 页面中的白色输入底。
- 让输入框、按钮、状态提示和字段标签统一进入当前终端设计体系。
- 保持表单语义、保存逻辑和测试行为不变。

## 设计方案

### 1. 深色输入面板

所有 `input` 改为使用 `--field-bg` 深色底和终端边框：

- 输入文字：`var(--text)`
- placeholder：`var(--text-faint)`
- 边框 hover / focus：青蓝色增强

### 2. 表单层级

- 字段标签从当前偏暗的 `var(--muted)` 提亮到 `var(--text-faint)`
- API key 的帮助文字保留次级层级，但不再发灰到难以阅读
- 保存按钮沿用当前青蓝终端按钮风格

### 3. 状态反馈

- 保存成功和失败提示保留正负语义
- 避免使用高饱和亮底，只使用文本或轻量描边语义

## 测试与验证

- 新增或扩展 `LlmSettingsView` 测试，锁定表单容器或输入框终端钩子。
- 跑该页面测试。
- 跑前端构建。
